About the System

ABOUT THE SYSTEM

An end-to-end AI prototype for predictive maintenance and intelligent condition monitoring.

01 — The Problem

Unexpected downtime is costly

Unexpected equipment failures can lead to downtime, maintenance costs, and operational disruption. Anticipating failure risk before it happens allows maintenance to be scheduled proactively rather than reactively.

02 — The Approach

Sensor data to recommendation

Sensor / Operational Inputs
↓
Feature Engineering
↓
Machine Learning
↓
Failure Risk + Anomaly Detection
↓
Health Assessment
↓
Maintenance-Oriented Recommendations
03 — Machine Learning Models

Three components, one assessment

XGBoost

Supervised gradient-boosting classifier used to estimate machine failure risk.

Isolation Forest

Unsupervised anomaly-detection algorithm used to identify unusual operating patterns.

SHAP

TreeSHAP explanations are computed for each saved XGBoost prediction and checked against its raw model margin.

04 — Features Used

Model inputs

Air Temperature Process Temperature Rotational Speed Torque Tool Wear Temperature Difference Power Temperature Ratio Product Type
05 — Dataset

AI4I 2020 Predictive Maintenance Dataset

The dataset used for model development is synthetic. It was used to develop and evaluate the predictive-maintenance prototype and does not represent real Renault vehicle data.

08 — Limitations

What this prototype is not

  • Dataset is synthetic.
  • This is a predictive-maintenance prototype.
  • It is not a validated automotive safety system.
  • Real deployment would require real sensor streams, domain validation, monitoring, and safety testing.
